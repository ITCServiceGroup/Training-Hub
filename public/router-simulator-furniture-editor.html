Router Simulator Layout Editor

Use this page while the Vite dev server is running to fine-tune furniture and fixed obstacle placement. Select an item, drag it into place, rotate furniture with the buttons or [ and ], nudge it with the arrow keys, then use Save To Source to write the current floorplan layout back into public/interactive-elements/router-simulator/floorplan.js.
